# Tudee 📝

A simple to-do app built with **Flutter** and **Firebase**.
Tasks are stored in the cloud using Cloud Firestore.

## Features

- Enter your name on the first launch (saved on the device)
- Add a new task
- Edit a task
- Mark a task as Done / To Do
- Delete a task
- Counters for Done and To Do tasks
- Tasks update instantly on screen (real-time)

## Tech Stack

| Part | Technology 
| Framework: Flutter (Dart) 
| Database: Cloud Firestore |
| Local storage: Shared Preferences (user name) |
| Design: Figma |

## How the Data Is Stored

Tasks are saved in the `tasks` collection:

```
tasks
 └── {taskId}
      ├── title: "Buy milk"
      ├── done: false
      └── createdAt: timestamp
```

## Getting Started

### 1. Requirements

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- A Firebase account
- Android Studio or VS Code

### 2. Clone the project

```bash
git clone https://github.com/AlshimaaAlnajjar/tudee_system.git
cd tudee_system
flutter pub get
```

### 3. Set up Firebase

1. Create a project in the [Firebase Console](https://console.firebase.google.com).
2. Go to **Firestore Database** and create a database in **Test mode**.
3. Connect the app to your project:

```bash
dart pub global activate flutterfire_cli
flutterfire configure
```

This creates the `firebase_options.dart` file for you.

> The `google-services.json` file is not included in this repo.
> Run `flutterfire configure` or download it from your own Firebase project
> and place it in `android/app/`.

### 4. Run the app

```bash
flutter run
```

## Troubleshooting

- **Android build error about minSdkVersion:** set `minSdkVersion` to 21 or 23 in `android/app/build.gradle`.
- **No tasks appear or permission denied:** Test mode in Firestore expires after 30 days, so check your Firestore rules.
- **Firebase is not initialized:** make sure you ran `flutterfire configure`.
